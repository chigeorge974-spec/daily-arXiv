Method: Proposes an adaptive robust loss function framework combining: 1) adaptive robust loss function to downweight contaminated data, 2) regularization term to prevent naive solutions, and 3) tuning parameter to control loss function shape and robustness level.

Result: Simulation results show the framework adapts to outliers within few iterations, while reverting to traditional L2 behavior when measurements are outlier-free, demonstrating effective robustness control.

Conclusion: The adaptive robust loss function framework provides effective outlier robustness for MHE with tunable adaptation, maintaining traditional performance with clean data while robustly handling contaminated measurements.

Abstract: In this work, we propose an adaptive robust loss function framework for MHE, integrating an adaptive robust loss function to reduce the impact of outliers with a regularization term that avoids naive solutions. The proposed approach prioritizes the fitting of uncontaminated data and downweights the contaminated ones. A tuning parameter is incorporated into the framework to control the shape of the loss function for adjusting the estimator's robustness to outliers. The simulation results demonstrate that adaptation occurs in just a few iterations, whereas the traditional behaviour $\mathrm{L_2}$ predominates when the measurements are free of outliers.
